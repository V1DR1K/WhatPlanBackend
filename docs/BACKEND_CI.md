# Backend CI status

The `Backend CI` workflow runs `mvn verify` with Java 21 for pushes and pull requests targeting `CoupleExpantion`. The GitHub-hosted Linux runner supplies Docker to the repository's PostgreSQL and Redis Testcontainers suites. It also runs a pinned OSV dependency scan and a pinned Gitleaks history scan, generates a CycloneDX SBOM, and retains Maven test reports plus the SBOM for 14 days. The workflow does not deploy. The `security-events: write` permission is restricted to the workflow's dependency-scanning purpose; repository contents are read-only and checkout credentials are not persisted.

The separate `Backend CI/CD` workflow on `main` now keeps Maven verification in a `contents: read` job and publishes the GHCR image only from a dependent, push-only job with `packages: write`. Pull-request builds do not receive package-write permission. The production deploy job remains explicitly disabled until the repository's `main` protection and the `production` environment's required reviewers are configured and verified.

This is a stronger C28 baseline, not a completed release gate. The PostgreSQL Testcontainers migration suite explicitly calls Flyway `validate()` after migrating. `CoupleHttpIsolationIntegrationTest` exercises the production JWT/filter/controller/data-source path against a restricted PostgreSQL runtime role and Redis. On 2026-09-26 it passed **5/5 tests** with PostgreSQL 16, Redis 7.4 and all 60 Flyway migrations validated/applied in disposable containers. Coverage includes A/B reads, forged `X-Couple-Id`, shared-member writes, personal reviews, private photos, admin/orphan denial, cross-couple deletes, updates and nested creates. Docker was unavailable locally, so this focused suite ran in a temporary Maven runner on the VPS; Testcontainers removed its services, the temporary workspace was removed, and no production service or data was changed. On 2026-09-26, `CoupleRowLevelSecurityTest` passed **12/12 tests** against disposable PostgreSQL 16, including runtime-role RLS enforcement and concurrent byte/photo-count quota checks that assert the exact quota constraint and final counters. The broader Maven/GitHub Actions workflow has not yet run successfully on GitHub. Remaining HTTP coverage includes additional cross-couple mutations (especially media) and complete review-author ownership cases; branch-protection enforcement, scan-finding triage and remote checks also remain unverified. No successful CI run is claimed until those checks execute.
