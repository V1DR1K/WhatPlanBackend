# Backend CI status

The `Backend CI` workflow runs `mvn verify` with Java 21 for pushes and pull requests targeting `CoupleExpantion`. The GitHub-hosted Linux runner supplies Docker to the repository's PostgreSQL and Redis Testcontainers suites. It also runs a pinned OSV dependency scan and a pinned Gitleaks history scan, generates a CycloneDX SBOM, and retains Maven test reports plus the SBOM for 14 days. The workflow does not deploy. The `security-events: write` permission is restricted to the workflow's dependency-scanning purpose; repository contents are read-only and checkout credentials are not persisted.

This is a stronger C28 baseline, not a completed release gate. The PostgreSQL Testcontainers migration suite explicitly calls Flyway `validate()` after migrating. The HTTP-level A/B authorization matrix, branch-protection enforcement, acceptance of any existing scan findings, and a successful GitHub-hosted workflow run remain unverified. No successful CI run is claimed until the workflow executes on GitHub.
